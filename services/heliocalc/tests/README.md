# HelioCalc Test and Benchmark Fixtures

This directory is the reserved test boundary for HelioCalc.

Authoritative calculation domains must be accompanied by deterministic tests and independent benchmark fixtures before release.

Planned structure:

```text
tests/
├── unit/
│   ├── pv/
│   ├── electrical/
│   ├── bess/
│   └── validation/
├── benchmarks/
│   ├── pv_electrical/
│   ├── electrical/
│   ├── bess/
│   └── performance/
├── regression/
├── integration/
└── fixtures/
```

Each benchmark fixture should preserve:

- fixture ID;
- domain;
- source/reference method;
- inputs with units;
- expected outputs;
- accepted tolerance;
- expected findings;
- scope/limitations;
- reviewer and validation date.

Known-answer fixtures must not be generated by the same HelioCalc function they validate.

See [`docs/TEST-VALIDATION-STRATEGY.md`](../../../docs/TEST-VALIDATION-STRATEGY.md) and [`docs/ENGINEERING-ACCURACY-VALIDATION.md`](../../../docs/ENGINEERING-ACCURACY-VALIDATION.md).
